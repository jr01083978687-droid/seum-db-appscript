# 네이버 플레이스 리뷰 사진 다운로더

플레이스 링크와 기간을 넣으면, 해당 플레이스의 **블로그리뷰 본문 사진**(선택 시 **방문자리뷰 사진**)을
PC 폴더에 모아 저장하는 윈도우 프로그램입니다.

## 받기 (exe)
1. GitHub 레포 → **Actions** → `place-photo-downloader (Windows exe)` → 최신 성공 실행 클릭
2. 아래 **Artifacts** 의 `PlacePhotoDownloader-windows` 다운로드 → 압축 해제 → `PlacePhotoDownloader.exe` 실행
   - 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행** (서명 없는 exe라서 뜨는 경고)
   - Python 설치 불필요. 윈도우 기본 **Edge** 브라우저를 사용합니다 (없으면 Chrome).

## 사용법
1. 플레이스 링크 붙여넣기 — `https://naver.me/...` 공유 링크, `map.naver.com/.../place/123`, `m.place.naver.com/restaurant/123` 모두 가능
2. 기간 입력 (`2026-07-01` 형식, 또는 1개월/3개월/6개월/1년 버튼)
3. [시작] → 브라우저 창이 열려 리뷰 목록을 넘기고, 끝나면 사진을 저장합니다
4. **네이버 보안확인(캡차)** 화면이 뜨면 열린 브라우저 창에서 직접 풀어주세요. 최대 3분 기다렸다 이어서 진행합니다.

## 저장 규칙
```
저장폴더/플레이스명/
  2026-09-12_블로그ID_01.jpg        블로그 본문 사진
  2026-09-12_블로그ID_03_영상.jpg   본문 동영상 썸네일
  2026-09-21_방문자_닉네임_01.jpg   방문자리뷰 사진 (옵션)
  _다운로드기록.json                재실행 시 이미 받은 사진 건너뛰기용 (지우면 처음부터 다시 받음)
저장폴더/_로그_날짜시간.txt
저장폴더/_진단/                     리뷰를 못 찾았을 때 원인 분석용 자료
```
- 제외: 스티커/이모티콘, 지도 이미지, 링크 미리보기 카드, **가로 300px 미만** 이미지
- 중복: 같은 URL 또는 같은 내용(해시)의 사진은 한 번만 저장
- 날짜 기준: 블로그 글 작성일 / 방문자리뷰 작성일

## 알아둘 점
- 네이버 비공식 화면 구조를 읽는 방식이라, 네이버 개편 시 동작이 멈출 수 있습니다.
  이때 `_로그_*.txt` 와 `_진단` 폴더를 전달해 주시면 수정합니다.
- 블로그리뷰 목록은 정렬이 최신순이 아닐 수 있어, 기간과 상관없이 **최대 확인 리뷰 수**(기본 300)까지 넘겨봅니다.
  리뷰가 많은 곳이면 이 값을 늘리세요.
- 저장된 사진의 저작권은 각 블로거/작성자에게 있습니다. 내부 분석/참고 용도로만 사용하세요.

## 개발
```
pip install -r requirements-dev.txt
python -m pytest -q tests      # 브라우저 흐름 테스트는 로컬 chromium 있을 때만
python app.py
```
